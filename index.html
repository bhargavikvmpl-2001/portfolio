[01] AI / RAG & LLM ENGINEERING

Codebase RAG Assistant

A retrieval-augmented Q&A service that answers natural-language questions about a 150K+ line real codebase (FastAPI's source and docs), grounding every answer in retrieved chunks with exact file#Lstart-Lend citations — not a "chat with a PDF" demo.

  • AST-aware chunking — splits Python at function/class boundaries instead of fixed-size windows, so a retrieved chunk is never a function cut in half.
  • Hybrid retrieval — fuses semantic search (Chroma cosine similarity) with BM25 keyword matching, since embeddings alone miss exact identifiers like APIRouter.
  • Pluggable generation — swaps between Anthropic, OpenAI, or a no-LLM extractive fallback behind the same API contract, with a Redis cache that degrades gracefully.
  • Reproducible evals — a retrieval-quality harness with numbers you can re-run, not just claims.
