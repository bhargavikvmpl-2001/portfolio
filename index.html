Distributed Web Crawler & Search Engine

github.com/…/distributed-web-crawler ↗

A fault-tolerant crawler where any worker can die mid-fetch without losing or duplicating work. All state — the frontier queue, dedup set, in-flight leases — lives in Redis behind one coordinator; workers stay pure compute. A lease expiring is the failure detector, so no separate dead-worker check is needed.

~30% fewer indexing bottlenecks lease-TTL requeue, no dead-worker detector
C++17gRPCRedisElasticsearchDockerKubernetes

Real-Time ML Feature Store

github.com/…/realtime-ml-feature-store ↗

Solves online/offline parity: the feature value a model sees at serving time and the value that same feature had at label time have to agree exactly. A single feature registry drives both a Redis sorted-set online store (sub-20ms reads) and a point-in-time-correct Spark backfill — plus a parity checker that measures the drift instead of assuming zero.

<20ms online read latency, measured zero label leakage via as-of-timestamp joins
PythonKafkaPySparkRedisPostgreSQLFastAPIAWS

Distributed Rate Limiter & API Gateway

github.com/…/distributed-rate-limiter ↗

Makes "check and consume a token" atomic across many gateway replicas hitting the same client at once, by pushing the whole token-bucket operation into a single Redis Lua script executed via EVALSHA. Proven, not asserted: a test fires 320 concurrent requests at a 50-token bucket and asserts exactly 50 are admitted.

50,000+ req/sec sustained 320/320 concurrent requests, exactly 50 admitted in test
